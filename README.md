# 内江职业技术学院新生助手 (TeleAgent Skill)

> 一个基于 TeleAgent 智能体平台的「新生助手」技能，覆盖内江职业技术学院新生入学常见问题，包含 17 章知识库 + 校园鸟瞰图。

## 技能简介

- **技能名称**：内江职业技术学院新生助手
- **技能 ID**：`新生助手_内江_内江职业技术学院`
- **覆盖范围**：报到流程、宿舍生活、食堂餐饮、军训攻略、学习指南、出行交通、医疗安全、财务管理、社团活动、校规校纪、周边生活、家长送校、学期日历等 17 章
- **知识库文件**：`references/knowledge_base.md`（约 32 KB，747 行）
- **校园地图**：`assets/campus_map.png`

## 使用方式

### 方式一：在 TeleAgent 中安装此技能

1. 下载本仓库的所有文件（点击绿色 `Code` 按钮 → `Download ZIP`，或 `git clone`）
2. 将 `新生助手_内江_内江职业技术学院` 文件夹复制到 TeleAgent 技能目录：
   - Windows 默认路径：`C:\Users\<用户名>\.config\TeleAgent\skills\`
   - macOS / Linux 默认路径：`~/.config/teleai-super-agent/skills/`
3. 重启 TeleAgent 桌面应用
4. 在对话中直接提问即可触发，例如：
   - "报到需要带什么材料？"
   - "宿舍是几人间？有空调吗？"
   - "军训什么时候开始？"
   - "怎么去学校？高铁站到学校多远？"

### 方式二：直接查看知识库

如果只需要查阅内容，直接打开 `references/knowledge_base.md` 即可，无需安装 TeleAgent。
